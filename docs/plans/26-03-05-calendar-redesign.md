# 캘린더 전면 리디자인 — Planit 참고, forme 스타일

## 목표

Planit 앱의 UX 구조(일정+투두 통합, 카테고리, 시간 관리)를 참고하되,
forme 디자인 시스템(Sky Blue, shadcn/ui, 다크모드, 미니멀+키치)에 어우러지게 구현.

## 1. 스키마 변경

### calendar_events 컬럼 추가

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `start_time` | varchar(5), nullable | "HH:mm", null이면 all-day |
| `end_time` | varchar(5), nullable | null이면 시작시간만 표시 |
| `location` | varchar(200), nullable | 장소 텍스트 |
| `category_id` | uuid, nullable, FK | 카테고리 참조 |
| `is_completed` | boolean, default false | 완료 체크 (Planit 핵심) |

### event_categories 신규 테이블

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `id` | uuid PK | |
| `user_id` | uuid, NOT NULL | RLS |
| `name` | varchar(50), NOT NULL | "업무", "개인" 등 |
| `color` | varchar(20), NOT NULL | hex 색상 |

기본 카테고리 4개 (첫 사용 시 자동 생성):
- 📋 업무 `#3b82f6` (blue)
- 👤 개인 `#22c55e` (green)
- 🤝 약속 `#f59e0b` (amber)
- 📚 공부 `#8b5cf6` (violet)

## 2. 월간 그리드 UI

### 전체 그리드 구조
```
┌─────────────────────────────────────────────┐
│  2026년 3월                    < 오늘 >     │
├──일──┬──월──┬──화──┬──수──┬──목──┬──금──┬──토──┤
│      │      │      │      │      │      │      │
│ ████████ 출장 ██████████████████████████████ │  ← 멀티데이 바 (주 상단, 셀 위에 겹쳐서)
│ 1    │ 2    │ 3    │ 4    │ 5    │ 6    │ 7    │
│10:00 │      │14:00 │      │      │15:00 │      │
│미팅  │      │점심  │      │      │스터디│      │
├──────┼──────┼──────┼──────┼──────┼──────┼──────┤
```

### 멀티데이 이벤트 스패닝 바
- 각 주(row) 상단에 고정 슬롯(최대 2줄)으로 배치
- 바가 셀을 가로질러 연결 — 시작 셀은 좌측 라운드, 끝 셀은 우측 라운드, 중간은 직선
- 주 경계에서 잘리면 → 다음 주 첫째 날부터 이어서 렌더 (좌측 직선)
- 바 색상: 카테고리 색상 `opacity 15%` 배경 + `opacity 100%` 텍스트
- 다크모드: 배경 `opacity 25%`로 올려서 가독성 확보
- 바 높이: 20px, 폰트 11px, 좌측에 emoji 아이콘

### 단일 이벤트 (셀 내)
- 시간 있음: `HH:mm 제목` — 좌측에 카테고리 색상 3px 세로 바
- all-day: 카테고리 색상 연한 배경 필(pill) + 제목
- 폰트: 11px (모바일), 12px (데스크톱), `text-muted-foreground`에서 색상 바가 구분점
- 최대 2개 표시 → 초과 시 `+N개` (muted 텍스트, 클릭하면 해당 날짜 선택)

### 날짜 셀 레이아웃
```
┌──────────┐
│ 5        │  ← 날짜 숫자: 좌상단, 작게 (12px)
│ ██ 출장  │  ← 멀티데이 바 슬롯 (셀 위 오버레이)
│ 10:00 미팅│  ← 단일 이벤트
│ 14:00 점심│  ← 단일 이벤트
│      ● 2 │  ← 우하단: 투두 미완료 수 (primary dot + 숫자)
└──────────┘
```
- 오늘: 날짜 숫자에 `bg-primary` 원형 배지
- 선택일: 날짜 숫자에 `bg-foreground` 원형 배지
- 일요일: `text-red-400`, 토요일: `text-blue-400`
- 셀 최소 높이: 모바일 72px, 데스크톱 90px
- 셀 호버: `bg-muted/30` 부드러운 하이라이트
- 셀 탭: 해당 날짜 선택 → 하단 상세뷰 스크롤/전환

### 투두 인디케이터
- 우측 하단에 작은 원형 뱃지: primary 색상 dot + 숫자
- 투두가 모두 완료면 표시 안 함 (클린)
- 투두 1개 미완료: `●` 만, 2개 이상: `● 3`

## 3. 하단 상세 뷰 (선택 날짜)

### 레이아웃 구조
```
┌─────────────────────────────────┐
│ 3월 5일 수요일           + 일정 │  ← 날짜 헤더 + FAB
├─────────────────────────────────┤
│                                 │
│  ── 일정 ──                     │
│  ┌─────────────────────────┐    │
│  │ ○  10:00 - 11:00        │    │  ← 체크 원 + 시간
│  │ │  팀 미팅               │    │  ← 카테고리색 좌측바 + 제목
│  │ │  📍 강남역 카페        │    │  ← 장소 (있을 때만)
│  └─────────────────────────┘    │
│  ┌─────────────────────────┐    │
│  │ ●  종일                  │    │  ← 완료된 일정 (취소선)
│  │ │  ~~프로젝트 마감~~     │    │
│  └─────────────────────────┘    │
│                                 │
│  ── 할 일 ──                    │
│  ┌─────────────────────────┐    │
│  │ ○ 마트 장보기            │    │
│  │ ○ 블로그 글 쓰기        │    │
│  │ ● ~~운동하기~~           │    │  ← 완료 (취소선 + muted)
│  └─────────────────────────┘    │
│                                 │
│  일정/할 일 없으면:             │
│  ┌─────────────────────────┐    │
│  │     (◕‿◕)               │    │  ← 귀여운 빈 상태
│  │   오늘은 여유로운 하루!   │    │
│  └─────────────────────────┘    │
│                                 │
└─────────────────────────────────┘
```

### 일정 카드 UX 디테일
- 좌측: 완료 체크 원형 (탭하면 토글, 완료 시 체크 + 취소선 + opacity 50%)
- 좌측바: 카테고리 색상 3px, 카드 높이 전체
- 우측: 더보기(···) 또는 탭하면 편집 다이얼로그
- 시간 표시: `10:00 - 11:00` 또는 `10:00` (end_time 없으면) 또는 `종일`
- 장소: `📍 장소명` — 있을 때만, muted 색상, 작은 폰트
- 완료된 일정: 하단으로 자동 정렬, 취소선 + 투명하게
- 빈 공간 탭: 빠른 일정 추가 (인라인 인풋 or 다이얼로그)

### 투두 섹션
- 기존 투두 리스트 패턴 유지 (optimistic updates, IME 처리)
- 스타일만 일정 카드와 통일 (좌측 체크원, 취소선 패턴)
- 완료된 투두: 접이식 "완료 N개" (토글로 펼치기)

### 날짜 전환 인터랙션
- 날짜 선택 시 하단 뷰가 `fade-in` (150ms) 부드럽게 전환
- 스와이프로 이전/다음 날짜 이동 가능 (좌우)

### 빈 상태
- DiceBear fun-emoji 또는 커스텀 이모티콘
- 날짜별 랜덤 멘트: "오늘은 여유로운 하루!", "한가한 하루네요 ☁️" 등
- `+ 일정 추가` 버튼 포함

## 4. 이벤트 폼 수정

### 폼 레이아웃 (Dialog, 모바일에선 바텀시트 느낌)
```
┌─────────────────────────────┐
│ 새 일정                  ✕  │
├─────────────────────────────┤
│                             │
│ [제목을 입력하세요      ]   │  ← 큰 폰트, 포커스 자동
│                             │
│ 카테고리                    │
│ [📋업무] [👤개인] [🤝약속] [📚공부] │  ← 가로 스크롤 칩
│                             │
│ 🕐 종일  ←────── 토글 ──→  │  ← Switch 토글
│                             │
│ 시작  [2026-03-05]  [10:00] │  ← 토글 off면 시간 숨김
│ 종료  [2026-03-05]  [11:00] │
│                             │
│ 📍 [장소를 입력하세요   ]   │  ← 선택사항
│                             │
│ 📝 [메모를 입력하세요   ]   │  ← 기존 description
│                             │
│ 🎨 색상 (카테고리 기본값)   │
│ [●] [●] [●] [●] [●] [●]   │  ← 카테고리 색상 자동, 수동 오버라이드
│                             │
│         [저장]              │  ← primary 버튼
│                             │
│ (수정 모드일 때)            │
│   [삭제]           [저장]   │  ← destructive + primary
└─────────────────────────────┘
```

### 폼 UX 디테일
- 제목 인풋: 20px 폰트, 밑줄 스타일 (미니멀), 자동 포커스
- 카테고리 칩: 선택 시 `ring-2` + 배경 연하게. 미선택 시 `border` + `muted`
- 종일 토글: shadcn Switch, on이면 시간 인풋 `slide-up`으로 사라짐
- 시간 인풋: 네이티브 `type="time"`, 모바일에서 OS 타임피커 활용
- 색상: 카테고리 선택하면 자동 세팅, 원하면 수동 변경 가능
- 날짜: 시작일 변경 시 종료일 자동 따라감 (기존 로직 유지)
- 저장 버튼: `w-full`, primary, 로딩 시 spinner

## 5. 카테고리 관리

### 진입점
- 이벤트 폼의 카테고리 칩 우측에 `+ 관리` 버튼
- 탭하면 카테고리 관리 다이얼로그 열림

### 관리 UI
```
┌─────────────────────────────┐
│ 카테고리 관리            ✕  │
├─────────────────────────────┤
│ [📋] [업무    ] [●색상]  ≡  │  ← emoji + 이름 + 색상 + 드래그핸들
│ [👤] [개인    ] [●색상]  ≡  │
│ [🤝] [약속    ] [●색상]  ≡  │
│ [📚] [공부    ] [●색상]  ≡  │
│                             │
│ + 카테고리 추가             │
└─────────────────────────────┘
```
- 각 행: emoji 피커 + 이름 인풋 + 색상 피커 + dnd-kit 드래그 핸들
- 스와이프 좌측 → 삭제 (또는 삭제 아이콘)
- 최대 8개 제한 (너무 많으면 UX 저하)
- emoji 선택: 클릭하면 작은 팝오버에 자주 쓰는 emoji 그리드

## 6. 기존 기능 유지

- 월 이동 스와이프 + 슬라이드 애니메이션
- 키보드 네비게이션 (화살표, T키)
- 투두 optimistic updates
- 대시보드 캘린더 위젯 (카테고리 색상 반영)

## 7. UX/UI 디자인 원칙

### forme 아이덴티티 유지
- **Sky Blue `#0ea5e9` 포인트**: 오늘 날짜, 선택 상태, 프로그레스, FAB
- **shadcn/ui 컴포넌트**: Card, Dialog, Switch, Button — 커스텀 최소화
- **Pretendard 폰트**: 캘린더 숫자도 동일 폰트 (일관성)
- **CSS 변수 기반 색상**: 하드코딩 절대 금지, 다크모드 자동 대응

### 모바일 퍼스트
- 셀 터치 영역 44px+ (애플 HIG 기준)
- 이벤트 텍스트는 모바일에서 1줄 truncate, 데스크톱에서 2줄
- 하단 상세뷰: 모바일에서 화면 절반 이상 차지, 스크롤 가능
- FAB(+ 일정 추가): 우하단 고정, 모바일에서 탭바 위

### 색상 체계 (이벤트/카테고리)
- 월간 그리드: 연한 배경(15% opacity) — 한눈에 구분되되 시끄럽지 않게
- 상세뷰: 좌측 바(3px, 100% opacity) — 포인트만 줌
- 다크모드: 배경 opacity 20-25%로 올리고, 텍스트는 밝은 톤으로
- 완료 상태: 전체적으로 `opacity-50` + 취소선 — "끝난 느낌"

### 인터랙션 & 트랜지션
- 셀 탭 → 하단뷰 전환: `fade-in 150ms ease-out`
- 월 이동: 기존 `slide-left/right 200ms` 유지
- 체크 토글: `scale(0.95)` → `scale(1)` 바운스 (완료 쾌감)
- 카테고리 칩 선택: `ring` 애니메이션 150ms
- 이벤트 삭제: `slide-out-left 200ms` + 높이 collapse

### 정보 밀도 밸런스
- 월간뷰: "한눈에 파악" — 색상 바와 짧은 텍스트로 밀도 조절
- 상세뷰: "디테일 확인" — 시간, 장소, 설명 다 보여줌
- 빈 날짜 셀: 깨끗하게 비워둠 (채우려 하지 않음)
- 오버플로 `+N`: 부담 없는 muted 색상, 클릭 유도

### 접근성
- 이벤트 색상만으로 구분하지 않음 — emoji 아이콘이 보조 역할
- 키보드 접근: 셀 간 이동, Enter로 상세뷰, Escape로 닫기
- 스크린리더: 각 셀에 aria-label (날짜 + 이벤트 수 + 투두 수)
