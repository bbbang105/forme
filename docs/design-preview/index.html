04 · typography

산세리프 본문, 세리프 악센트.

Pretendard로 UI 전체를 지탱하고, Instrument Serif는 제목·로고·장식 숫자에만 제한적으로. 공책 감성은 믹스가 아니라 여백·행간·가중치로.
